Detecting Atrial Fibrillation Using an ECG Filtering Model

  • MATLAB
  • Signal Processing
  • Time-domain Signal Analysis
  • ECG Filtering

Overview

Atrial Fibrillation is a common condition that has seen an increase in diagnosis in recent years. As of 2024, approximately 10.5 million individuals live with AFib, which has a detrimental effect on the person's overall heart health. An earlier diagnosis of AFib would enable patients to begin preventive measures sooner, improving quality of life.

The project addresses AFib detection by scanning 12-plot ECG readings and detecting irregular RR intervals and absent P waves, both typical symptoms of someone suffering from AFib.

Approach

MATLAB code was made to filter ECG data using a bandpass filter to minimize low/high frequency inputs, detrending to minimize baseline wander, and time domain analysis to correctly identify lengths of certain intervals.

Lead II plots were analyzed due to the association of lead II plots with conistent RR intervals and P wave presence.

Outcome

Graphs were switched to time domain and analyzed using MATLAB code. RR intervals were compared, and the presence of P waves were also being considered. The code found local maximums (R peaks) and compared distances between with a threshold difference. Local maximums were also found right before the R peaks, indicating the presence or absence of a P interval. The code prints "Consistent R intervals." and "Consistent P waves." if they are consistent, and if not, it will print warnings.

This project demonstrated the ability to detect the presence of Atrial Fibrillation using software and a lead II plot. Currently, personal fitness wearable companies are beginning to incorporate ECG monitors into their devices and are receiving FDA approval to market said devices. People being able to rely on software for daily ECG monitoring and AFib detection would be incredibly useful for catching the irregularity early on.
